# MarketPilot

> A desktop research and portfolio management platform for rules-based investing.

MarketPilot is a Python application designed to help investors build, test, and execute systematic investment strategies.

The initial focus is implementing the A-RVol v3 strategy for leveraged ETFs, but the long-term goal is to create a flexible research platform capable of supporting multiple investment strategies, portfolio tracking, backtesting, and optimization.

---

## Vision

MarketPilot is designed around three core principles:

- **Objectivity** – Make investment decisions using predefined rules instead of emotions.
- **Transparency** – Every recommendation should explain *why* it was made.
- **Research** – Every strategy should be testable using historical market data.
