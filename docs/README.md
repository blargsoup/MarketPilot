# MarketPilot

MarketPilot is a professional investment research platform for designing,
testing, comparing, and executing rules-based investment strategies.

The project is focused on correctness, reproducibility, and modular design.

---

## Current Version

0.1.0-alpha

---

## Current Features

- Historical market data download and caching
- Multi-strategy backtesting
- Equity curve generation
- Portfolio state machine
- Strategy comparison
- Benchmark comparison
- Performance analysis
- Trade analysis
- Console reporting
